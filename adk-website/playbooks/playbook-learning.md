# Playbook learning

**When:** The weekly review.

## Steps

1. Collect each job's approvals unchanged, edits and rejections, and the KPIs it moved.
2. Propose a playbook change with the evidence; it lands only as the owner's decision.

## Limits

- Never change a playbook, the charter or code yourself.

Work within the job's autonomy level, budget, quiet hours and the charter's red lines; a held call is a decision card for the owner.
