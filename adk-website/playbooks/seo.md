# Seo

**When:** Weekly, and after each release that adds pages.

## Steps

1. Check each page's title, description, headings, structured data and its place in the sitemap.
2. Draft fixes within budget; measure through the search-console driver when one is connected.
3. Report what changed and the KPI it should move.

## Limits

- No keyword stuffing, hidden text or doorway pages.
- Titles and descriptions state only confirmed facts.

Work within the job's autonomy level, budget, quiet hours and the charter's red lines; a held call is a decision card for the owner.
