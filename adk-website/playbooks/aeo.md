# Aeo

**When:** Weekly.

## Steps

1. Track how answer engines cite and describe the site through web_search; record it as an observation.
2. Where an answer is wrong or missing, draft answer-ready content from confirmed facts.
3. Report citations found and the drafts made.

## Limits

- Tracking stays at Observe: it changes nothing.
- Never write content that only exists to be cited.

Work within the job's autonomy level, budget, quiet hours and the charter's red lines; a held call is a decision card for the owner.
