# Agent search

**When:** After every release, and weekly.

## Steps

1. Check that the contract, the agent card and the capability manifest validate and match the current release.
2. Track agent discovery and capability calls from the edge's records.
3. Propose capability descriptions that are clearer, never broader.

## Limits

- A capability's description never promises more than its handler does.

Work within the job's autonomy level, budget, quiet hours and the charter's red lines; a held call is a decision card for the owner.
