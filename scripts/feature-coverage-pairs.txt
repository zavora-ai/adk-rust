# Feature-gated modules the default workspace build never compiles, and the CI shard
# that builds and tests each one (`scripts/check-feature-coverage.sh <shard>`). A shard
# groups pairs that share heavy dependencies, so each shard compiles them once.
#
# Format: <shard> <package> <features> [flags]. Features are comma-separated with no spaces;
# flags too: `no-default` builds with `--no-default-features`, `doc` also runs the doctests.
# To cover another feature-gated module, add ONE line and pick the shard whose crates it
# already depends on. Shards are numbered 0 to 7; `ci.yml` lists the same range.

# Shard 0 — adk-rag backends. lancedb pulls the whole lance/datafusion tree and is the
# slowest pair; it stays in the PR tier because an arrow version mismatch once sat broken
# on main for weeks with nothing compiling the LanceDB backend.
0 adk-rag lancedb
# sqlx-backed backend: a second sqlx major entering the graph through pgvector went unnoticed.
0 adk-rag pgvector
0 adk-rag vertex-rag
0 adk-rag agent-retrieval
# The in-process ONNX embedder downloads the onnxruntime binary at build time (R1).
0 adk-rag onnx
# The encrypted store, its SQLite backends and the local embedder (spec 3.1 §7.12, §7.15.2);
# the workspace build reaches adk-harness only through adk-cli's feature set.
0 adk-harness encrypted,sqlite,memory-embeddings-local
