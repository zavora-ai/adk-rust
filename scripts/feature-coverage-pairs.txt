# Feature-gated modules the default workspace build never compiles, and the CI shard
# that builds and tests each one (`scripts/check-feature-coverage.sh <shard>`). A shard
# groups pairs that share heavy dependencies, so each shard compiles them once.
#
# Format: <shard> <package> <features>. Features are comma-separated with no spaces.
# To cover another feature-gated module, add ONE line and pick the shard whose crates it
# already depends on. Shards are numbered 0 to 6; `ci.yml` lists the same range.

# Shard 0 — adk-rag backends. lancedb pulls the whole lance/datafusion tree and is the
# slowest pair; it stays in the PR tier because an arrow version mismatch once sat broken
# on main for weeks with nothing compiling the LanceDB backend.
0 adk-rag lancedb
# A surrealdb 3.2 parser change broke create_collection while every required check stayed
# green; tests run on the embedded kv-mem engine.
0 adk-rag surrealdb
# sqlx-backed backend: a second sqlx major entering the graph through pgvector went unnoticed.
0 adk-rag pgvector
0 adk-rag vertex-rag
0 adk-rag agent-retrieval

# Shard 1 — the adk-rust umbrella. `graph` alone gives adk-graph its default (empty)
# features, so the umbrella forwards are built explicitly.
1 adk-rust graph-sqlite
1 adk-rust graph-functional
# Code-execution opt-ins outside every tier: embedded JS/Python, persistent Docker, and
# the CodeActAgent + MontyRuntime forward. `code-tools` itself is covered by the `full`
# builds in docs/examples.
1 adk-rust code-embedded-js,code-embedded-python,code-docker,codeact-monty
# Enforces the meta-feature growth rule structurally: a forgotten umbrella forwarding
# fails this build once the constituent is referenced. The `-full` variant (realtime
# stack) is nightly-only.
1 adk-rust gemini-agent-platform
