# builds (scripts/ci-scope.py). A job runs when one of its crates changed or depends,
# directly or through other workspace crates, on one that did.

# Format: <job> <crate or standalone example directory>...

# project. An example directory stands for the files under it and the workspace crates its
# manifest names by path. A job absent from this file runs on every change to code.
# scripts/tests/test_ci_scope.py holds each row to the commands the job runs.
