- **Cancelling an A2A task cancels the remote tasks it waits on** (`adk-server`, `adk-core`, `a2a-v1`): when a caller cancels an `INPUT_REQUIRED` task whose pending calls came from a `RemoteA2aV1Agent`, the server finds those calls' events in the task's session, reads the remote task each names (`a2a:task_id`), and asks the remote agent to cancel it for the session's user, as adk-go's executor does. A failed cancel is logged and does not fail the caller's cancel. `Agent::cancel_remote_task` (new, defaulted to doing nothing) is how an agent cancels a task it started elsewhere; `RemoteA2aV1Agent` implements it with its card, binding and credentials.
