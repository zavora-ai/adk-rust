- **A2A v1 extension negotiation** (`adk-server`, `a2a-v1`): as a2a-go does, the server reads the extensions a caller asks for from the `A2A-Extensions` request header (`RequestedExtensions`), refuses a call that leaves out an extension the agent card marks `required` with `ExtensionSupportRequired` (-32008, or 400 on HTTP+JSON), and hands the requested extensions to each run's hooks (`ExecutionContext::extensions`).
