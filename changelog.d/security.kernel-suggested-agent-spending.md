- **A suggested agent spends at most its suggester** (`adk-kernel`; spec 3.3 S-I12):
  `AgentCeiling` carries the suggester's daily spending limit, lowered to its area's; a
  suggestion above it is refused when made and again when approved, and one naming no limit
  is kept with the suggester's, so the card shows it. Where the kernel has more than one
  area, a suggestion from a run the kernel does not know is refused, since it might come
  from any area.
