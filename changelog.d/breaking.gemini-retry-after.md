- **Gemini HTTP errors preserve Retry-After** (`adk-gemini`, `adk-model`): AI Studio and Vertex REST errors retain the raw header, and the model facade attaches parsed delays through the existing shared retry owner. `ClientError::BadResponse` gains `retry_after: Option<String>`; callers constructing this variant must add the field (use `None` when absent). Exhaustive field patterns can add `..`. Successful responses, status classification and retry-policy defaults are unchanged.
