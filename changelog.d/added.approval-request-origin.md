- **`ApprovalRequest::origin`** (`adk-core`; spec 3.3 §7.1): the request a held call becomes
  names who publishes the tool — `ApprovalRequest::new` copies the call's `ToolOrigin`, and
  `with_origin` sets one — so a surface tells one publisher's cards from another's without
  parsing the fingerprint or trusting a tool name an MCP server can copy. Approval stores keep
  it inside the stored request, so no migration runs; a request stored before it reads with
  none. Code that builds an `ApprovalRequest` with a struct literal adds `origin`.
