The `adk-rust` harness commands (`repl`, `code`, `goal`, `ultracode`, `serve`) install a `tracing` subscriber on stderr: `RUST_LOG` sets the filter, `warn` is the default, so a `warn!` or `error!` from the harness — a failed session-end distillation among them — is no longer silent. `Harness::close_with_report` returns the sessions whose distillation failed, and the CLI prints one line per failure: `note: long-term memory was not updated for session <id>: <error>` (spec 3.1 §7.15.2, §8.1).
