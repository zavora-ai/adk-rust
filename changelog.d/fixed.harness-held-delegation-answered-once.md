`Harness::set_mode` and the stranded-call settlement answer a delegation that holds several member calls once per call id, and `harness.held.cancelled` and `harness.mode.changed` list the id once; a loosening wrote one cancellation response per held member call under the same id (spec 3.1 §7.4, §10 F4).
