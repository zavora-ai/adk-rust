- **MCP elicitation on the decision card** (`adk-surface`): an MCP server's form elicitation is
  drawn in the home's own fields from its schema (`DecisionCard.elicitation`,
  `ElicitationView`), answered with **Answer** (the decision's edit) and checked against the
  fields before it is on record; before, the home could only refuse one. A URL elicitation
  shows the host on its own line and the whole address as text, with a warning for look-alike
  characters, a name before an `@` or plain `http`. Chat cards never carry either.
  An elicitation's card is headed by what the server asks ("MCP server billing asks: …"),
  not by the tool name it was parked under.
